# Adnan Maqbool — Business Universe V2

Next.js + TypeScript concept build for the immersive Adnan Maqbool portfolio.

## Local preview

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Next.js.

## Deploy

This project is structured for Vercel. After the final content/visual pass, import the project into Vercel, keep the defaults, and deploy.

## Notes

- The page uses the supplied portrait and a cropped supplied image of *The Unfinished Map*.
- The experience is built around the supplied factual CV content plus the current role/context provided by Adnan during the conversation.
- Replace `metadataBase` in `app/layout.tsx` with the final public domain before production.
